# Job observability operations

Run migrations through the Backend container before starting Flask. MySQL is private; back it up according to the deployment owner's RPO/RTO policy.

`WORKER_ID` must be an explicit stable host/instance name in production. The Worker maintains Redis heartbeat and replays output receipts without rerunning ComfyUI. Pending dispatches are replayed by Flask; duplicate queue delivery is harmless because the MySQL claim is conditional.

Dashboard errors are sanitized. The public gallery intentionally exposes submitted prompts and the first persisted output through `GET /api/history`; dispatch payloads already contain prompts. Tracebacks and storage URIs are not returned by this endpoint. For a stuck job, inspect structured Worker logs, ComfyUI history using `comfyui_prompt_id`, then let the timeout reconciler mark it failed rather than re-running GPU work blindly.

The shared gallery requires `JOB_OBSERVABILITY_ENABLED=true` and access to the existing MySQL database in both local-dev and TWCC. The code default is false; compose enables it. No new environment variables, tables, or migrations are required. `GET /api/history` defaults to completed jobs, supports offset pagination and status filters, and never uses Redis or membership. Disabled observability or database failure returns a fixed 503 response, not an empty result. Every visitor sees the same Web-origin prompts and works; dispatches with `user_label=line` are excluded from both items and total before pagination. LINE files, delivery, and downloads remain unchanged. No delete API is provided. Removing files manually does not delete MySQL job history; unavailable media displays a notice and removes its download link. TWCC deployment owners must confirm the MySQL connection and flag separately because `deployment_matrix.yaml` is absent from this repository.

All admin responses declare `output_encoded=false`. The browser must use context-safe DOM properties (`textContent` for text and same-origin allowlisted paths for output links); the server does not HTML-encode JSON. There is no authentication, user identity, JWT, API key, OAuth, or RBAC in this change.

Admin routes use the existing Flask port: `/admin`, `/api/admin/metrics/summary`, `/api/admin/metrics/timeseries`, `/api/admin/jobs`, `/api/admin/errors`, `/api/admin/workflows`, `/api/admin/workers`, and `/api/admin/system/health`. Queries default to 24 hours, are limited to 31 days, and page size is at most 200. Canonical states are `created`, `queued`, `running`, `completed`, `failed`, and `cancelled`; legacy status responses remain `queued`, `processing`, and `finished`.
